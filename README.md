Pizza Sales Analytics Dashboard
📌 Project Summary

This project presents an end-to-end data analysis of pizza sales using SQL for data transformation and Power BI for interactive visualization. The objective is to derive actionable insights into sales performance, customer behavior, and product trends to support data-driven decision-making.

🛠️ Tech Stack
SQL (MySQL / SQL Server) – Data cleaning, normalization, and KPI computation
Power BI – Data modeling, DAX calculations, and dashboard development
🗂️ Data Modeling & Architecture

The original dataset was restructured and normalized into a relational schema to improve data integrity and analytical efficiency:

Pizza Table – Product category and type information
Pizza Details Table – Size and pricing attributes
Orders Table – Order date and time details
Order Details Table – Transaction-level sales data

Relationships were established between tables to enable efficient querying and reporting within Power BI.

🧹 Data Preparation
Handled missing and inconsistent values
Removed duplicate records
Standardized data formats (date, time, categorical fields)
Performed table normalization for optimized querying
Created calculated fields and measures for analysis
📊 Key Metrics (KPIs)
Total Revenue: 817.86K
Total Pizzas Sold: 50,000+
Order Volume Analysis
Average Order Value (AOV)
Sales Distribution by Category and Size
🔍 Business Insights
Thai Chicken Pizza emerged as the top revenue-generating product
Significant variation observed in sales across different pizza sizes
Peak sales hours identified, indicating high-demand periods
Category-level analysis revealed clear customer preferences and demand patterns
📈 Dashboard Highlights
Interactive sales performance overview
Time-based trend analysis (daily/hourly patterns)
Product-level performance insights
Category and size-wise revenue distribution
Dynamic filtering for enhanced user exploration
🎯 Objectives Achieved
Transformed raw transactional data into structured analytical datasets
Delivered clear insights into sales trends and product performance
Enabled stakeholders to identify high-performing products and peak demand periods
Built an interactive dashboard for real-time business analysis
